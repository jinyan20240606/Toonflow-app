# AI 漫剧固定角色音色：概要方案

## 目标

保留图生视频模型生成的环境音、动作声和背景音乐，去掉其中不可控的随机人声，再为主角及常驻人物换成固定的专属音色。

## 简单流程

```text
生成带声音的视频
  ↓
Demucs或其他轻量化工具 分离人声与背景音效
  ↓
删除模型生成的原始人声，保留背景音效
  ↓
AI 从分镜描述中提取“角色 + 台词 + 顺序”
  ↓
主角/常驻人物使用绑定的专属音色
其他临时人物使用普通预设音色
  ↓
TTS 生成各角色台词
  ↓
ffmpeg 将背景音效、TTS 台词和视频画面重新合成
  ↓
输出最终视频
```

## 使用的工具

- **Demucs**：分离原视频中的人声和背景音效。
- **TTS**：把台词文字生成语音。
- **专属音色引擎**：后续从 OpenVoice V2、GPT-SoVITS 或云端音色克隆 API 中选择。
- **ffmpeg**：提取音轨、排列配音、混音并输出视频。
- **现有角色绑定数据**：记录哪些角色需要使用固定音色。

## 音色规则

- 主角和常驻人物：提前绑定一份有授权的参考音频，长期使用同一专属音色。
- 每集临时人物：不创建专属音色，使用系统预设音色或自动匹配音色。
- 旁白：可作为一个独立常驻角色绑定固定音色。

## Toonflow 后续接入位置

视频在以下流程生成并保存后，自动启动配音后处理：

- `src/routes/production/workbench/generateVideo.ts`
- `src/routes/production/workbench/batchGenerateVideo.ts`

角色音色绑定继续复用现有的 `o_assetsRole2Audio` 数据关系；台词来源使用 `o_storyboard.videoDesc`。

## 实施前再确定

后续正式实施时，只需再确定一项：专属音色采用本地 OpenVoice V2、GPT-SoVITS，还是云端音色克隆 API。纯 CPU、低成本方向优先评估 OpenVoice V2；最终以实际中文音质和处理速度测试结果为准。

## 验证目标

1. 原视频的环境音和动作音基本保留。
2. 模型随机人声被去除。
3. 主角和常驻人物跨分镜、跨集保持固定音色。
4. 临时人物无需提前配置。
5. 处理失败时保留原始视频，不影响正常生成流程。
